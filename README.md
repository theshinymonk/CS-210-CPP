# CS-210-CPP

This is my work for Project 3 in my CS 210 class. This code is to simulate a scenario where a grocery store needs a program that analyzes the data from text records that shows what items were purchased throughout the day. The grocer needs to have the options to search for a product and see how often it was sold, to see a total list of all the items and how often they were sold, and to output a histogram of that same list. There is also an option to exit the program too.

I feel that I handled keeping main small fairly well, and I like the use of a switch statement for the menu options. I was also pretty happy with the use of maps, as I had to read up on them, and didn't know how to use them before this project. This was also the first time that I tried omitting the use of "using namespace std", as a way of challenging myself and I feel it turned out well, even though it took some getting used to at first. I am happy with this code, but as is usually the case, as soon as I submitted it I saw areas I could have improved. For one I could have use a try/catch instead of the while loop to handle input validation, and I could have made the menu input validation into a function to futher remove clutter from main.

The most challenging aspect of this was figuring out how to utilize maps for the first time, and to figure out exactly when I was going to need to use std:: , due to omitting "using namespace std". I am happy that I decided to go with these challenges though, as I will be able to use both of these skills moving forward. I feel I did a good job of keeping the code readable, for maintenance, and by keeping most actions to functions that the code should be easily adaptable for the future.
